# EncounterAfterglow Research Contract

## Primary promise

Give an adult a private, local-only space to reflect on their own experience
after an encounter, identify what they may want in the future, and delete or
export the reflection on their own terms.

## Object constraints

- The reflection is opened only by a user action.
- The platform does not infer that an encounter happened.
- The object has no server API, synchronization, background upload, telemetry,
  cloud backup, user-to-user visibility, or counterpart linkage.
- The reflection is not a rating, reputation event, report, complaint, safety
  score, trust score, match signal, or moderation input.
- The entry contains no counterpart account identifier, profile identifier,
  corridor identifier, exact location, schedule, chat transcript, photo, or
  encounter identifier.
- The user may choose session-only storage, encrypted local-expiring storage,
  or encrypted local storage until deletion.
- Export occurs only after an explicit user request.
- The user can delete one entry or all local entries immediately.
- The object never contacts a match, platform reviewer, third party, emergency
  contact, employer, venue, authority, or service.

## Always-stop conditions

- Any reflection content is transmitted from the browser.
- Any entry is linked to another user, profile, corridor, appointment, location,
  message, or discovery event without an explicit user-authored local label.
- Any afterglow field affects discovery, ranking, recommendation, advertising,
  moderation, eligibility, reporting, or research metrics.
- The platform automatically prompts a reflection based on inferred encounter
  behavior.
- A user cannot clearly export, expire, or delete local content.
- Local content appears in browser analytics, error reports, autofill, search
  indexing, application logs, or cloud backup created by Hearthline.
- An accessibility-equivalent workflow is unavailable.
- Any external action is initiated from an afterglow entry.

## Permitted measures

- User-reported clarity and control gathered separately from entry content.
- Accessibility task-completion outcomes using synthetic entries.
- Explicit participant feedback about retention controls.
- Aggregate test results confirming that no network requests occur.

## Prohibited measures

- Reflection-content analysis.
- Encounter-quality scoring.
- Counterpart ratings.
- Safety, trust, desirability, or compatibility scoring.
- User behavior prediction.
- Location, schedule, identity, health, recovery, finance, or vulnerability
  inference.
- Any data transmission derived from private entries.
